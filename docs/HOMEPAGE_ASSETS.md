# Homepage visual

The homepage uses real HTML for its copy, navigation, feature cards, search dialog and calls to action. The laptop and panda are an illustrative scene, not a live or guaranteed rendering of the workspace. Feature card art displays selected areas of the same generated asset through CSS backgrounds.

- Asset: `public/marketing/holyai-workspace-hero.webp` (1942 × 809).
- Method: built-in imagegen tool, with the user's supplied HOLYAI design as the visual reference. Converted to WebP for web delivery without changing the composition.
- The page shows the project's 18 configured features and 4 categories. It does not copy unverified user counts, uptime figures, or a 150+ feature claim from the reference.
- The public navigation uses existing feature, workflow and privacy pages, plus a help page. Pricing and community services were not introduced by this visual change.
